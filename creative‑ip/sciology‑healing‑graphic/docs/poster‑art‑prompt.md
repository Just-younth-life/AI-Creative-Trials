# poster‑art‑prompt｜海报AI绘画提示词库&视觉规范
## 🎨IP统一视觉风格定义（固定基底，保证系列辨识度）
风格关键词：水彩拼贴、低饱和莫兰迪色调、安静疏离、氛围感、柔和光影、杂志剪贴质感，极简构图，留白充足，无尖锐线条，文艺治愈，略带沉静忧郁，不要二次元、不要网红ins风。
画幅比例：3:4竖版海报（适配小红书、公众号、印刷明信片）

## ✅通用基底模板（每次生成先粘贴本段，再追加主题描述）
>竖版3:4，水彩杂志剪贴拼贴艺术，柔和低饱和莫兰迪配色，大量留白，朦胧柔光，安静疏离氛围感，极简构图，细腻纹理，高级人文质感，无多余杂物，文艺治愈，沉静克制，不要艳丽色彩，无卡通，厚纸肌理，高清，细腻质感

## 📌分主题示例提示词
### 案例1｜群体性孤独
基底模板 + 破碎的玻璃窗，遥远微弱光点，人与人之间隔着薄雾，孤独孤岛，朦胧雾气，安静夜晚
### 案例2｜自我驱动倦怠
基底模板 + 一根不断绷紧快要断裂的细线，昏暗柔和光线，散落干枯书页，安静疲惫感，没有激烈情绪
### 案例3｜工具理性
基底模板 + 老旧钟表齿轮缠绕柔软植物，冰冷机械与温柔自然形成对比，光影朦胧

## 📏视觉规范（保证IP统一，避免风格漂移）
1.禁止高饱和亮色、浓烈撞色；
2.画面留白≥40%，为文字slogan预留位置；
3.拒绝写实人像特写，多用隐喻意象（孤岛、薄雾、细线、齿轮、植物、书页）；
4.不堆砌过多元素，一张海报只承载一个意象。

## 💡迭代规则
每次产出满意海报后，记录prompt、画面优缺点，持续优化模板，沉淀为本项目专属资产。
