# core‑theory｜理论溯源与概念深度剖析
## 项目底层理论来源
马克斯·韦伯「工具理性/价值理性」、理查德·桑内特「公共人的衰落」、雪莉·特克尔《群体性孤独》、韩炳哲《倦怠社会》、鲍曼《流动的现代性》。

## 概念逐条剖析（可直接用于海报文案/长图文）
### 1.工具理性
我们只关心手段、效率、产出、可量化结果，不再追问生活本身的意义。
效率成为最高准则，工作、学习、休息甚至情绪都被任务化、指标化。
>金句：工具理性许诺更多掌控感，最后只留给我们永不停歇的疲惫。

### 2.自我驱动的隐性规训（韩炳哲倦怠社会）
不再是外部压迫，而是个体不断自我催促、自我苛责。
我们自愿内卷，把自我优化当成终身使命，在无休止的自我提升中耗竭。
>金句：敌人不再是别人，是永不停止鞭策自己的我。

### 3.群体性孤独
线上连接无限充裕，沟通变多却越来越浅。
社交软件消除距离，却建立一座座孤岛；我们时刻在线，却难以获得深度共鸣。
>金句：我们连接一切，唯独无法抵达彼此。

### 4.悬浮感｜流动现代性
物质充足，但归属感消失。没有稳定的扎根支点，人生持续漂泊。
不断追逐下一个目标，抵达之后依旧空虚。

## ✍理论使用规范（产品准则）
1. 拒绝晦涩学术术语堆砌，把社会学概念转化成普通人能共情的情绪痛点；
2. 不制造焦虑，不贩卖抑郁，核心是**看见困境，接纳痛苦，获得和解**；
3. 每条海报只聚焦**一个社会学命题**，不多个概念混杂，保证情绪纯粹；
4. 文案克制留白，把理论藏在感受背后，避免说教感。

## 📋素材库：海报可用金句合集
1. 我们拥有无限连接，却活成一座座相互遥望的孤岛。（群体性孤独）
2. 不是懒惰困住我们，是无休止的自我鞭策将我们耗竭。（自我规训）
3. 工具理性带来效率，却抽空了生活本身的意义。
4. 时代提供一切便利，却很难给我们一处可以扎根的土壤。（悬浮感）
5. 我们习惯把人生拆解成KPI，却遗忘活着不需要全部有产出。
6. 在线的人越来越多，真正的对话越来越少。
7. 我们不断优化自己，直到疲惫成为日常底色。
8. 丰裕没有治愈空洞，只是放大了空洞。
